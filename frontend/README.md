# Frontend (React + Vite + TypeScript)

1. `npm install`
2. Copia `.env.example` a `.env` (URL del backend NestJS)
3. `npm run dev` -> http://localhost:5173

## Colores
Todo el tema está en `src/styles/theme.css` (variables CSS).
- Cambia los colores de un tema editando sus variables.
- Agrega un tema nuevo: copia un bloque `[data-theme='...']` y añádelo a `THEMES` en `src/theme.ts`.

## Nombre de la marca
`src/config/brand.ts`
